# 生产提示词模板

这些模板是结构，不是无条件复制的固定文案。先把方括号内容替换为真实商品信息，删除不适用段落。

## 商业分析

```text
根据我提供的商品资料和商品图片，完成商品商业分析。
输出：1. 产品定位 2. 目标用户画像 3. 核心卖点3–5条
4. 竞争优势 5. 品牌关键词 6. 适合的视觉方向。
将“图片可确认”“用户资料确认”“未确认”的信息分开标注，不臆造参数、成分、认证和功效。
```

## 商品精修

```text
以用户商品原图为唯一商品身份依据。保持商品外观、颜色、比例、结构、Logo、包装和可见文字不变。
修复灰尘、轻微划痕、不均匀反光和抠图边缘；优化材质、高光、阴影和边缘细节。
使用简洁高级背景，商品是绝对主体，达到品牌级商业摄影质量。
不重绘包装，不添加虚假文字、认证或配件。
```

## 多视角商品图

```text
保持商品外观、包装、颜色、比例和结构完全一致。
生成正面、侧面、背面、45度、俯视和仰视角度。
纯色背景，统一焦段、光线、商品尺度和色彩。
如无法从现有照片推断某视角，不得虚构隐藏结构；先要求补充参考照片。
```

## 主视觉

```text
结合已确认的商品分析、精修图和品牌定位，设计3个可选主视觉方向。
每个方向确定配色、场景、光影、构图、商品占比、标题留白和品牌氛围。
为商品区、标题区、副标区和卖点证据区指定明确位置与占比，背景的文案区保持低纹理和足够对比。
画面突出商品主体，可作为后续主图、详情页和海报的统一视觉依据。
底图不生成复杂文字、价格或虚假参数。
```

## 3秒主图

```text
基于商品真相表、竞品结论和已确认的主视觉，生成一张[商品识别/USP/事实证据/信任/场景/转化决策]主图底图。
该图唯一核心卖点是[卖点]，画面证据是[实物、参数、结构或场景]。
商品是绝对主角，不遮挡Logo、包装文字和重要结构。
道具只起衬托作用。在[具体留白位置及约占画布比例]保留低纹理文案区，文字区与商品轮廓保持安全距离。
正方形构图，缩略图中仍能识别商品和卖点。
不在底图内生成中文、价格、促销或认证。
```

排版阶段另行加入 10 字以内的核心标题、最多一行必要副标和最多 2–3 条短证据；使用确定性中文图层，不让生成模型绘制最终文字。具体层级和版式见 [文字排版与信息层级](typography-layout.md)。

## 模特/使用场景

```text
保持商品外观、颜色、包装、比例和结构一致。
根据目标用户和已确认的主视觉，选择匹配的模特或使用者，生成自然真实的穿戴/使用场景。
风格、配色、光影和镜头与主视觉一致，使用动作真正展示[核心卖点]。
人物不遮挡商品的关键结构和Logo，不生成多余手指、错误接触或不合理姿势。
```

## 多尺寸海报

```text
保持商品、品牌元素和主视觉一致。
分别生成竖版、横版和正方形的营销海报底图，为标题、副标和行动信息预留安全区。
不改变商品比例与包装，不在底图中生成未确认价格和促销。
```

## Mockup样机

```text
保持已确认设计稿的内容、比例和视觉层级不变。
将设计稿应用于[手机界面/产品包装/广告牌/展架/橱窗/线下展示空间]的真实场景。
保持透视、反光、材质和环境光合理，突出商业展示效果。
```

## 详情页结构

```text
根据商品定位、目标用户和已确认卖点，规划完整详情页结构。
建议包括：商品认知、核心USP、产品细节、功能或事实证据、使用场景、规格/使用提示与购买理由。
输出每一屏的设计目标、唯一核心信息、画面证据、文案层级、商品区/文字区排版地图和与上下屏的逻辑关系。
不直接生成整张长图，后续按分屏逐张生成。
```
